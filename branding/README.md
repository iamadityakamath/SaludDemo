# Branding

Drop the logo for the tagging page here as one of:

- `logo.svg` (preferred: crisp at any size)
- `logo.png`, `logo.webp`, `logo.jpg`

The page shows it in the header (about 30 px tall, up to 140 px wide) and uses it as the browser-tab icon.
If several files exist, the first in the order above wins. With no logo, a "QA" mark is shown instead.
Restarting `salud-qa tag` isn't needed; reload the page.
